# Сборка Marlin для Beta M V1.1

## База

Использовалась ветка Marlin **2.1.2.8** и PlatformIO. Плата определяется собственной записью `BOARD_LOTMAXX_V1_7`, окружение PlatformIO - `lotmaxx_V1_7`.

Нужны:

- Git;
- Python 3;
- PlatformIO Core (`pio` в `PATH`);
- SD-карта FAT32 для загрузчика контроллера.

```powershell
git clone --branch 2.1.2.8 https://github.com/MarlinFirmware/Marlin.git marlin-2.1.2.8
cd marlin-2.1.2.8
pio run -e lotmaxx_V1_7
```

Результат: `.pio/build/lotmaxx_V1_7/firmware.bin`.

### Публичный бинарник

Перед публикацией проверить строки BIN: отладочные `__FILE__` могут включить абсолютный путь каталога PlatformIO. Для релизной сборки добавьте в `build_flags` пути, заменённые на нейтральный корень:

```ini
-ffile-prefix-map=<локальный-каталог>=.
-fmacro-prefix-map=<локальный-каталог>=.
```

После сборки убедитесь, что `strings firmware.bin` не содержит имя пользователя, домашний каталог, ключи или токены.

## Прошивка контроллера

1. Переименовать результат в `SM3DP.bin`.
2. Положить **один** этот файл в корень SD-карты.
3. Вставить карту в слот контроллера и включить принтер.
4. После успешного обновления загрузчик переименует файл в `OLDSM3DP.BIN`.
5. Выключить принтер, извлечь карту, включить снова и проверить `M115`.

Не обновляйте одновременно контроллер и DWIN. Это разные носители и разные процедуры.

## Ключевая конфигурация

### Плата

В `Marlin/src/core/boards.h` добавить идентификатор платы, а в `Marlin/src/pins/stm32f4/pins_LOTMAXX_V1_7.h` - базовую распиновку из [BOARD.md](BOARD.md).

Минимальные определения лазера:

```cpp
#define SPINDLE_LASER_ENA_PIN       PE3
#define SPINDLE_LASER_PWM_PIN       PE13
#define LOTMAXX_LASER_POWER_PIN     PE9
#define LOTMAXX_LASER_ENABLE_PIN    PE12
#define LASER_DET_PIN               PD8
#define LASER_MIN_PIN               PD9
#define LASER_MIN_ENDSTOP_INVERTING true
```

`PD8` исторически назван detector, однако физически это `/PL` регистра `74HC165`. Не строить автоматический выбор режима только на этом входе.

### `Configuration.h`

```cpp
#define MOTHERBOARD BOARD_LOTMAXX_V1_7
#define X_BED_SIZE 250
#define Y_BED_SIZE 250
#define Z_MAX_POS 265
#define TEMP_SENSOR_0 1
#define TEMP_SENSOR_BED 5
```

Подберите термисторы по реальному оборудованию и обязательно проверьте их показания. Приведённые значения - отправная точка, а не разрешение отключать защиту.

### `Configuration_adv.h`

```cpp
#define LASER_FEATURE
#define SPINDLE_LASER_ACTIVE_STATE LOW
#define SPINDLE_LASER_USE_PWM
#define SPINDLE_LASER_PWM_INVERT false
#define SPINDLE_LASER_FREQUENCY 1000
#define CUTTER_POWER_UNIT PWM255
```

Частота 1 kHz соответствует измеренной заводской V1.6 на `PE13`.

## Требуемая логика для этой платы

Обычного `LASER_FEATURE` недостаточно. Для воспроизведения работы платы нужны следующие действия:

1. При выборе Laser-режима поднять `PE9` (24 V драйвера) и `PE12` (силовой каскад).
2. Перед применением PWM перевести `PE13` в GPIO output, записать начальный уровень и затем назначить PWM. На STM32 это воспроизводит последовательность, при которой `M42` показал рабочий результат.
3. `PE3` использовать как active-low enable, но не полагаться на него как на единственный ключ: его маршрут внутри драйвера ещё не подтверждён.
4. `PD9` назначить лазерным Z-концевиком; в Laser-режиме `G28 Z` не должен искать X/Y.
5. После `G28 Z` поднять Z на настраиваемую фокусную высоту. Команда `M954 Z<мм>` должна сохранять эту высоту в EEPROM, а `M954` - её показывать.

## LightBurn-совместимость в Marlin

Профиль LightBurn Marlin в этой конфигурации использует:

```gcode
M106 S0
G0 X... Y...
M106 S255
G1 X... Y...
```

Поэтому в Laser-режиме `M106 S0..255` надо переназначить с вентилятора на лазерный PWM `PE13`; `M106 S0` и `M107` выключают PWM и enable. Каждый переход должен быть синхронизирован с планировщиком движения. Иначе парсер успеет выполнить следующий `M106 S255` до реального `G0`, что прожжёт переход между векторами.

Дополнительно полезна совместимость со старой прошивкой:

```gcode
M2 S0..1000  ; сохранить мощность в заводской шкале
M3           ; включить
M5           ; выключить
```

## Контроль после сборки

До печати проверить:

```gcode
M115
M105
M119
M503
```

Перед лазерным заданием проверить с расфокусированной головой:

```gcode
M950 S1
M106 S0
M106 S20
M106 S0
```

`M950 S1` здесь означает ручной выбор Laser-режима. Для обычной печати верните `M950 S0`, если такая логика включена в вашей реализации.

## Что не включать в рабочую ветку

- тесты `M42` на силовых GPIO;
- принудительные состояния `PD8`, `PE9`, `PE12`;
- отключение thermal runaway, MAXTEMP или проверок термисторов;
- DWIN-пакеты, не проверенные на штатном RJ9-экране.
