# LightBurn и Marlin

## Профиль

На исследованной конфигурации LightBurn Pro 2.1.04 в профиле **Marlin device** формирует G-code следующего вида:

```gcode
G21
G91
M8
M106 S0
G0 X... Y...
M106 S51
G1 X... Y... F6000
M9
M106 S0
```

Значение `M106 S0..255` - мощность, где `255` равно 100 %. Это не стандартный `M3 S...`-путь Marlin, поэтому прошивка должна обрабатывать `M106` в Laser-режиме как управление PWM `PE13`.

`M8` и `M9` - air assist. Если на устройстве нет отдельного управляемого air assist, их можно принимать как no-op; они не должны быть причиной включения или выключения луча.

## Обязательное условие: порядок движения и PWM

Векторная работа содержит многократные последовательности:

```gcode
M106 S0
G0 X... Y...
M106 S255
G1 X... Y...
```

Смена PWM должна быть синхронизирована с очередью движения:

- перед `M106 S0` дождаться завершения предыдущего прожига;
- выполнить `G0` с выключенным лазером;
- перед `M106 S<n>` дождаться завершения `G0`.

Без синхронизации прошивка быстро разбирает будущий `M106 S255`, пока `G0` ещё физически выполняется, и оставляет прожжённые линии между сегментами.

## Проверка без задания

Сначала включить Laser-режим и убедиться, что силовая часть работает:

```gcode
M950 S1
M106 S0
M106 S20
M106 S0
```

Проверять только в защитных очках, на расфокусированной голове, с безопасной подложкой. После команды `M106 S0` луч должен погаснуть. Далее выполнить короткий вектор с хотя бы одним `G0` между двумя `G1` и убедиться, что переход не маркируется.

## Фокус и home

В Laser-режиме home должен быть только по Z:

```gcode
G28 Z
```

После нахождения концевика нужно отъехать на фокусную высоту. Для прошивки с поддержкой этой настройки:

```gcode
M954 Z15.000  ; установить и сохранить высоту в EEPROM
M954          ; показать сохранённое значение
```

После калибровки можно освободить двигатели X/Y:

```gcode
M84 X Y
```

## Заводской формат

Заводская V1.6 использует другой протокол:

```gcode
M2 S1000
M3
...
M5
```

Не ожидайте, что импорт старого `lgcode`, просто переименованного в `.gcode`, будет полноценно работать в LightBurn без адаптации прошивки или постпроцессора.
