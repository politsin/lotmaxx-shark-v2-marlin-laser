# Вложенный бинарник

`SM3DP.bin` - сборка текущего экспериментального Marlin для Beta M V1.1.

Загрузчик ожидает это имя в корне SD-карты. После успешного обновления он обычно переименовывает файл в `OLDSM3DP.BIN`.

Этот образ предназначен для воспроизведения документированного лазерного пути и совместимости LightBurn. Он **не является готовым безопасным релизом для 3D-печати**: перед 3D-печатью необходимо восстановить нормальную термозащиту и проверить реальные показания хотэнда и стола на своём оборудовании. См. [../docs/STATUS.md](../docs/STATUS.md).

Контрольная сумма находится в `SHA256SUMS.txt`.
