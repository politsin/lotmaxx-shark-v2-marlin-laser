# Заводская прошивка контроллера V1.6

`SM3DP-1.6.BIN` - исходный рабочий образ контроллера Lotmaxx Shark V2, отображаемый как `SC-10Shark-v1.6`. Это стабильная контрольная точка для штатной 3D-печати и штатного лазерного режима вместе с пакетом [DWIN V1.6](../../dwin/README.md).

## Установка

1. Использовать SD-карту контроллера, а не microSD в экране.
2. Оставить в корне карты ровно один контроллерный образ и назвать его `SM3DP.bin`.
3. Включить принтер. После удачной обработки загрузчик обычно переименовывает файл в `OLDSM3DP.BIN`.
4. Проверить на экране версию и до нагрева выполнить обычную проверку термисторов, концевиков и направлений осей.

Не помещайте каталог `DWIN_SET` на эту карту: он предназначен только для microSD внутри DWIN-экрана.
