# Заводской пакет DWIN V1.6

`DWIN_SET/` - исходный рабочий пакет ресурсов штатного экрана Shark V2. Он соответствует стабильной контроллерной прошивке [`SC-10Shark-v1.6`](../firmware/original/README.md), а не экспериментальному Marlin.

## Установка

1. Использовать отдельную microSD, вставляемую в слот DWIN-экрана.
2. Отформатировать её в FAT32 с размером кластера 4096 байт.
3. Скопировать каталог `DWIN_SET` из этого репозитория в корень карты, сохранив все имена и содержимое файлов.
4. Вставить карту в выключенный экран и включить питание. На синем сервисном экране DWIN должны появиться ненулевые счётчики загруженных CFG, Code, BIN, DZK, HZK и ICL файлов.
5. После завершения выключить питание, извлечь карту и снова включить принтер.

Не помещайте `SM3DP.bin` на карту экрана. Контроллерная прошивка устанавливается другой картой в основной SD-слот платы.

Имена трёх файлов `.icl` зависят от кодировки Windows и могут выглядеть по-разному в веб-интерфейсе. Это штатные файлы пакета; не переименовывайте их.

Контрольные суммы всех файлов: [SHA256SUMS.txt](SHA256SUMS.txt).
